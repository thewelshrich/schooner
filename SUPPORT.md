# Support

Schooner is maintained as an open-source project. Support is best effort and
does not include a guaranteed response time.

## Before asking for help

1. Read the [README](README.md) and the [documentation index](docs/README.md).
2. Run `schooner version` and `schooner doctor`.
3. Search existing issues for the behavior or question.
4. Remove secrets and identifying infrastructure details from any output you
   plan to share.

## Where to ask

- Use a bug report for reproducible incorrect behavior.
- Use a feature request to describe a user problem or proposed improvement.
- Consult the [roadmap](docs/roadmap.md) before proposing a large change.
- Use GitHub's private reporting flow described in [SECURITY.md](SECURITY.md)
  for a suspected security vulnerability.

Schooner does not currently operate a separate real-time support channel.
Please do not send support requests through vulnerability reports.

When reporting a problem, include the smallest reproduction, the relevant
redacted output from `schooner version` and `schooner doctor`, and whether the
problem affects macOS, Linux, or a supported remote Ubuntu system.
